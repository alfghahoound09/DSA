Stack & Queue

Giải thích trực quan về hai cấu trúc dữ liệu nền tảng: Stack (Ngăn xếp) và Queue (Hàng đợi) với animation tương tác

📥
Stack — Ngăn xếp

Cấu trúc dữ liệu hoạt động theo nguyên tắc LIFO (Last In, First Out) — phần tử vào sau cùng được lấy ra đầu tiên.

🧠 Hiểu nhanh qua ví dụ thực tế

🍽️

Chồng đĩa

Đĩa đặt lên trên cùng sẽ được lấy ra trước. Bạn không thể rút đĩa ở giữa mà không lấy đĩa trên ra.

↩️

Nút Undo (Ctrl+Z)

Mỗi thao tác được push vào stack. Khi undo, thao tác gần nhất (trên cùng) được pop ra và hoàn tác.

🌐

Lịch sử trình duyệt

Nút Back quay lại trang gần nhất trước đó — đúng nguyên tắc LIFO.

🔄

Call Stack (Đệ quy)

Khi gọi hàm đệ quy, hàm gọi cuối cùng sẽ return trước — hệ thống dùng stack để quản lý.

🔄 Nguyên tắc LIFO

Bước 1
Push A
→
Bước 2
Push B
→
Bước 3
Push C
→
Pop
Ra C !

C vào sau cùng nhưng lại được lấy ra đầu tiên → Last In, First Out

📊 Độ phức tạp (Time Complexity)

Push
O(1)*
Pop
O(1)
Peek
O(1)
Search
O(n)
Space
O(n)

* Push là O(1) amortized — thỉnh thoảng phải resize mảng (O(n)) nhưng trung bình vẫn là O(1).

💻 Code Java — Stack (Array-based)

Java 
public class Stack {
    private int[] data;   // Mảng lưu trữ phần tử
    private int top;      // Index phần tử trên cùng (-1 = rỗng)

    public Stack() {
        this.data = new int[10];
        this.top = -1;
    }

    // Thêm phần tử vào đỉnh stack
    public void push(int value) {
        if (top == data.length - 1) resize(data.length * 2);
        data[++top] = value;
    }

    // Lấy và xóa phần tử đỉnh
    public int pop() {
        if (isEmpty()) throw new RuntimeException("Stack Underflow!");
        int val = data[top--];
        if (top > 0 && top == data.length / 4) resize(data.length / 2);
        return val;
    }

    // Xem phần tử đỉnh mà KHÔNG xóa
    public int peek() {
        if (isEmpty()) throw new RuntimeException("Stack rỗng!");
        return data[top];
    }

    public boolean isEmpty() { return top == -1; }
    public int size()      { return top + 1; }
}

Queue — Hàng đợi

Cấu trúc dữ liệu hoạt động theo nguyên tắc FIFO (First In, First Out) — phần tử vào trước được lấy ra trước.

🧠 Hiểu nhanh qua ví dụ thực tế

🎫

Xếp hàng mua vé

Người đến trước sẽ được phục vụ trước. Không ai được chen hàng — đúng FIFO.

🖨️

Hàng đợi máy in

Tài liệu gửi trước sẽ được in trước, các tài liệu gửi sau sẽ chờ trong hàng đợi.

💬

Tin nhắn chat

Tin nhắn gửi trước hiển thị trước — thứ tự được bảo toàn nhờ queue.

🔍

BFS (Duyệt theo chiều rộng)

Thuật toán BFS sử dụng queue để duyệt qua tất cả đỉnh theo từng "lớp" kề nhau.

🔄 Nguyên tắc FIFO

Bước 1
Enqueue A
→
Bước 2
Enqueue B
→
Bước 3
Enqueue C
→
Dequeue
Ra A !

A vào đầu tiên và cũng được lấy ra đầu tiên → First In, First Out

📊 Độ phức tạp (Time Complexity)

Enqueue
O(1)
Dequeue
O(1)
Peek
O(1)

O(n)
Space
O(n)

Triển khai bằng Linked List giúp enqueue và dequeue đều O(1) mà không cần resize.

💻 Code Java — Queue (Linked-List-based)

Java 
public class Queue {
    private static class Node {
        int data;
        Node next;
        Node(int data) { this.data = data; }
    }

    private Node front, rear;
    private int count;

    // Thêm vào cuối hàng đợi
    public void enqueue(int value) {
        Node node = new Node(value);
        if (isEmpty()) { front = rear = node; }
        else { rear.next = node; rear = node; }
        count++;
    }

    // Lấy ra từ đầu hàng đợi
    public int dequeue() {
        if (isEmpty()) throw new RuntimeException("Queue rỗng!");
        int val = front.data;
        front = front.next;
        if (front == null) rear = null;
        count--;
        return val;
    }

    public int peek()     { return front.data; }
    public boolean isEmpty() { return front == null; }
    public int size()      { return count; }
}

So sánh Stack vs Queue

Hai cấu trúc dữ liệu nền tảng, mỗi loại phù hợp với những bài toán khác nhau.

📋 Bảng so sánh tổng quan

Tiêu chí 📥 Stack 🚶 Queue
Nguyên tắc LIFO (Last In, First Out) FIFO (First In, First Out)
Thêm phần tử push() — thêm vào đỉnh enqueue() — thêm vào cuối
Lấy phần tử pop() — lấy từ đỉnh dequeue() — lấy từ đầu
Xem phần tử peek() — xem đỉnh peek() — xem đầu
Triển khai phổ biến Array / Linked List Linked List / Circular Array
Insert / Remove O(1) O(1)
Search O(n) O(n)
Ví dụ thực tế Undo, Call Stack, DFS Xếp hàng, BFS, Scheduler

📥 Khi nào dùng Stack?

↩️
Undo / Redo

Lưu lại lịch sử thao tác, hoàn tác theo thứ tự ngược.

🧮
Tính biểu thức

Chuyển Infix → Postfix, tính toán biểu thức hậu tố.

🔄
Đệ quy

Hệ thống dùng Call Stack để quản lý các lời gọi hàm.

🗺️
DFS (Duyệt sâu)

Duyệt đồ thị/cây theo chiều sâu bằng stack.

✅
Kiểm tra ngoặc

Balanced Parentheses — kiểm tra chuỗi ngoặc có hợp lệ không.

📜
Lịch sử trình duyệt

Nút Back/Forward sử dụng hai stack.

🚶 Khi nào dùng Queue?

🔍
BFS (Duyệt rộng)

Duyệt đồ thị/cây theo chiều rộng, xử lý từng "lớp".

⏰
Task Scheduling

Hệ điều hành xếp lịch CPU cho các tiến trình.

🖨️
Print Queue

Hàng đợi tài liệu chờ in — in theo thứ tự gửi.

📨
Message Queue

Hệ thống tin nhắn (Kafka, RabbitMQ) xử lý message theo FIFO.

🚗
Traffic / Buffer

Bộ đệm mạng, hàng đợi request HTTP.

🎮
Game Event Queue

Xử lý input người chơi theo thứ tự nhấn.

💡 Tóm tắt nhanh

📥

Stack = "Chồng đĩa"

Dùng khi bạn cần xử lý theo thứ tự ngược — thao tác gần nhất được xử lý trước. Nghĩ đến: Undo, DFS, đệ quy.

🚶

Queue = "Xếp hàng"

Dùng khi bạn cần xử lý theo thứ tự đúng — ai đến trước phục vụ trước. Nghĩ đến: BFS, scheduling, buffer.
