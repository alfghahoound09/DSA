🔴 Selection Sort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Mỗi vòng lặp, tìm phần tử nhỏ nhất trong phần chưa sắp, rồi đổi chỗ nó với phần tử đầu tiên của phần chưa sắp.
🎴 Ví von thực tế

Giống như bạn có 1 đống bài lộn xộn. Bạn nhìn qua toàn bộ để tìm quân nhỏ nhất, rút nó ra đặt vào đầu. Rồi lại nhìn qua phần còn lại, tìm quân nhỏ nhất tiếp theo, đặt vào vị trí thứ 2... Cứ thế cho đến hết.

💻 Code Java — Selection Sort

Java 
public class Selection {
    public static void sort(Comparable[] a) {
        int N = a.length;
        for (int i = 0; i < N; i++) {           // duyệt từng vị trí
            int min = i;                           // giả sử a[i] nhỏ nhất
            for (int j = i+1; j < N; j++)        // tìm min thực sự
                if (less(a[j], a[min])) min = j;
            exch(a, i, min);                       // đổi chỗ a[i] ↔ a[min]
        }
    }

    private static boolean less(Comparable v, Comparable w) {
        return v.compareTo(w) < 0;
    }

    private static void exch(Comparable[] a, int i, int j) {
        Comparable temp = a[i]; a[i] = a[j]; a[j] = temp;
    }
}

⏱️ Compares

~N²/2 phép so sánh. Luôn quét hết phần còn lại.

🔄 Swaps

Chỉ N lần swap — ít nhất trong các sort cơ bản!

⚠️ Không Adaptive

Input đã sắp hay chưa đều chạy ~N²/2 comparisons.

🟢 Insertion Sort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Giống cách bạn sắp bài trên tay: lấy từng lá bài mới, rồi đẩy nó sang trái cho đến khi nó nằm đúng vị trí trong phần đã sắp.
🃏 Ví von thực tế

Khi chơi bài, tay trái bạn cầm các lá đã sắp. Tay phải rút 1 lá mới, rồi chen vào đúng vị trí giữa các lá bên tay trái. Nếu lá mới nhỏ hơn lá bên trái nó → đổi chỗ, cứ lùi dần cho đến khi đúng chỗ hoặc hết bên trái → dừng.

⚡ Điểm mấu chốt — DỪNG SỚM

Khi gặp phần tử bên trái ≤ mình → dừng ngay (else break). Đây là lý do Insertion Sort rất nhanh trên dữ liệu gần sắp (nearly sorted)!

💻 Code Java — Insertion Sort

Java 
public class Insertion {
    public static void sort(Comparable[] a) {
        int N = a.length;
        for (int i = 0; i < N; i++)                   // duyệt từng phần tử
            for (int j = i; j > 0; j--)                 // đi ngược về trái
                if (less(a[j], a[j-1]))             // nếu a[j] < a[j-1]
                    exch(a, j, j-1);                // đổi chỗ, tiếp tục lùi
                else break;                            // ĐÃ ĐÚNG CHỖ → dừng sớm!
    }
}

🏆 Best case: ~N

Input đã sắp → mỗi phần tử chỉ cần 1 compare → O(N)

💀 Worst case: ~N²/2

Input sắp ngược → mỗi phần tử phải swap đến đầu mảng

✅ Stable

Giữ nguyên thứ tự tương đối của các phần tử bằng nhau — quan trọng trong thực tế!

🔵 Shellsort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Insertion Sort nhưng so sánh phần tử cách nhau h vị trí (thay vì 1). Giảm dần h cho đến 1 → mảng sắp xong.
🏃 Tại sao nhanh hơn?

Insertion Sort yếu vì: phần tử nhỏ ở cuối mảng phải nhích từng ô 1 để về đầu → rất chậm. Shellsort cho phần tử nhảy vọt h ô cùng lúc. Khi h giảm dần, mảng đã "gần sắp" → lúc h=1 (Insertion Sort thường), chỉ cần vài swap nữa!

💻 Code Java — Shellsort

Java 
public class Shell {
    public static void sort(Comparable[] a) {
        int N = a.length;

        int h = 1;
        while (h < N/3) h = 3*h + 1;    // Knuth: 1, 4, 13, 40, 121, ...

        while (h >= 1) {                    // giảm dần h
            for (int i = h; i < N; i++) {   // h-sort = Insertion Sort bước h
                for (int j = i; j >= h && less(a[j], a[j-h]); j -= h)
                    exch(a, j, j-h);
            }
            h = h / 3;                    // ..., 40 → 13 → 4 → 1
        }
    }
}

📊 Complexity

~O(N^{3/2}) với Knuth sequence — tốt hơn N² rất nhiều!

🌍 Thực tế

Dùng trong Linux kernel, bzip2, uClibc — code rất ngắn mà hiệu quả.

❓ Bài toán mở

Dãy h tối ưu vẫn chưa ai tìm được — vẫn là open problem!

🟡 Knuth Shuffle — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Duyệt từ trái sang phải, tại vị trí i chọn vị trí ngẫu nhiên r trong [0, i], rồi đổi chỗ a[i] và a[r]. Mọi hoán vị đều có xác suất bằng nhau.
⚠️ Lỗi cực kỳ phổ biến

Nếu chọn r trong toàn bộ [0, N-1] thay vì [0, i] → kết quả KHÔNG đều! Slide nhắc đến vụ kiện online poker vì dùng shuffle sai, gây thiệt hại hàng triệu đô.

💻 Code Java — Knuth Shuffle

Java 
public static void shuffle(Object[] a) {
    int N = a.length;
    for (int i = 0; i < N; i++) {
        int r = StdRandom.uniformInt(i + 1);  // random [0, i] ← quan trọng!
        exch(a, i, r);
    }
}

⏱️ O(N)

Chỉ duyệt 1 lần, mỗi phần tử swap 1 lần → tuyến tính.

🎯 Uniform

Mọi N! hoán vị đều có xác suất 1/N! — chứng minh được bằng quy nạp.

🔷 Merge Sort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Chia đôi mảng thành 2 nửa, sắp xếp đệ quy từng nửa, rồi trộn (merge) hai nửa đã sắp lại thành một mảng sắp.
🃏 Ví von thực tế

Giống như bạn có 2 chồng bài đã sắp sẵn. Bạn lấy lá nhỏ nhất ở đầu mỗi chồng, so sánh, đặt lá nhỏ hơn xuống bàn. Cứ thế cho đến hết cả 2 chồng → chồng mới trên bàn cũng đã sắp!

💻 Code Java — Merge Sort

Java 
public class Merge {
    private static Comparable[] aux;       // mảng phụ cho merge

    public static void sort(Comparable[] a) {
        aux = new Comparable[a.length];
        sort(a, 0, a.length - 1);
    }

    private static void sort(Comparable[] a, int lo, int hi) {
        if (hi <= lo) return;            // base case
        int mid = lo + (hi - lo) / 2;
        sort(a, lo, mid);                  // sắp nửa trái
        sort(a, mid + 1, hi);              // sắp nửa phải
        merge(a, lo, mid, hi);             // trộn 2 nửa đã sắp
    }

    private static void merge(Comparable[] a, int lo, int mid, int hi) {
        for (int k = lo; k <= hi; k++)    // copy sang mảng phụ
            aux[k] = a[k];
        int i = lo, j = mid + 1;
        for (int k = lo; k <= hi; k++) {
            if      (i > mid)              a[k] = aux[j++]; // hết nửa trái
            else if (j > hi)               a[k] = aux[i++]; // hết nửa phải
            else if (less(aux[j], aux[i]))  a[k] = aux[j++]; // phải < trái
            else                           a[k] = aux[i++]; // trái ≤ phải
        }
    }
}

⏱️ O(N log N)

Luôn là N log N — best, average, worst đều giống nhau. Đảm bảo hiệu suất.

✅ Stable

Giữ nguyên thứ tự tương đối các phần tử bằng nhau — Java dùng cho Object sort!

💾 Space: O(N)

Cần mảng phụ aux[] kích thước N — không in-place. Đây là nhược điểm chính.

🔧 Các cải đặt (Improvements) — Merge Sort

🔄

Top-Down (đệ quy)

Chia đôi đệ quy → merge ngược lên. Cách tiêu chuẩn, dễ hiểu, dễ cài đặt. Gọi sort(a, lo, hi) rồi chia tại mid.

⬆️

Bottom-Up (không đệ quy)

Merge các cặp kích thước 1, rồi 2, rồi 4, 8... Không cần đệ quy, dùng vòng lặp. Phù hợp linked list.

⚡

Cutoff to Insertion Sort

Khi mảng con nhỏ (≤ 7~15 phần tử), chuyển sang Insertion Sort vì overhead đệ quy quá tốn cho mảng nhỏ.

🧪

Test if already sorted

Nếu a[mid] ≤ a[mid+1] → 2 nửa đã sắp, bỏ qua merge. Tiết kiệm thời gian cho dữ liệu gần sắp.

🔀

Eliminate copy (switcheroo)

Luân phiên vai trò a[] và aux[] giữa các tầng đệ quy → bỏ bước copy vào aux. Nhanh hơn ~20%.

🧠

Natural Merge Sort

Tìm các run (đoạn đã sắp sẵn) trong dữ liệu, rồi merge các run. Rất nhanh trên dữ liệu gần sắp — cơ sở của Timsort.

💻 Code Java — Bottom-Up Merge Sort

Java 
public class MergeBU {
    private static Comparable[] aux;

    public static void sort(Comparable[] a) {
        int N = a.length;
        aux = new Comparable[N];
        for (int sz = 1; sz < N; sz = sz+sz)      // sz: 1, 2, 4, 8, ...
            for (int lo = 0; lo < N-sz; lo += sz+sz) // merge cặp kích thước sz
                merge(a, lo, lo+sz-1, Math.min(lo+sz+sz-1, N-1));
    }
}

🟠 Quick Sort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Chọn 1 phần tử làm pivot, rồi phân hoạch (partition) mảng: mọi phần tử nhỏ hơn pivot nằm bên trái, lớn hơn nằm bên phải. Lặp lại đệ quy cho từng phần.
🎴 Ví von thực tế

Giống như bạn chọn 1 lá bài chốt, rồi chia đống còn lại thành 2 nhóm: nhóm nhỏ hơn chốt (bên trái) và nhóm lớn hơn chốt (bên phải). Lá chốt đã đúng vị trí. Rồi lặp lại cho mỗi nhóm — cuối cùng tất cả đều đúng chỗ!

⚡ Điểm mấu chốt — PARTITION

Partition là trái tim của Quick Sort: dùng 2 con trỏ i (trái→phải) và j (phải→trái) quét tìm cặp sai vị trí rồi swap. Khi i vượt j → dừng, swap pivot vào đúng chỗ.

💻 Code Java — Quick Sort

Java 
public class Quick {
    public static void sort(Comparable[] a) {
        StdRandom.shuffle(a);           // shuffle trước để đảm bảo hiệu suất
        sort(a, 0, a.length - 1);
    }

    private static void sort(Comparable[] a, int lo, int hi) {
        if (hi <= lo) return;
        int j = partition(a, lo, hi);  // partition: a[j] đúng chỗ
        sort(a, lo, j - 1);            // sắp nửa trái
        sort(a, j + 1, hi);            // sắp nửa phải
    }

    private static int partition(Comparable[] a, int lo, int hi) {
        int i = lo, j = hi + 1;
        while (true) {
            while (less(a[++i], a[lo]))  // tìm a[i] ≥ pivot từ trái
                if (i == hi) break;
            while (less(a[lo], a[--j]))  // tìm a[j] ≤ pivot từ phải
                if (j == lo) break;
            if (i >= j) break;           // con trỏ giao nhau → dừng
            exch(a, i, j);                // swap cặp sai vị trí
        }
        exch(a, lo, j);                   // đưa pivot vào đúng chỗ
        return j;
    }
}

⏱️ Average: ~2N ln N

Trung bình ~1.39 N lg N comparisons. Nhanh hơn Merge Sort ~39% so sánh nhưng thực tế nhanh hơn nhờ cache.

💀 Worst: N²/2

Khi mảng đã sắp + không shuffle → mỗi partition chỉ giảm 1 phần tử. Shuffle trước để tránh!

📦 In-place

Chỉ cần O(log N) stack cho đệ quy. Không cần mảng phụ — ưu thế so với Merge Sort!

🔧 Các cải đặt (Improvements) — Quick Sort

🔀

Random Shuffle

Shuffle mảng trước khi sort — tránh worst case N². Đây là bước cực kỳ quan trọng, đảm bảo xác suất O(N log N).

⚡

Cutoff to Insertion Sort

Khi subarray ≤ 10 phần tử, chuyển sang Insertion Sort vì overhead đệ quy không đáng cho mảng nhỏ. Cải thiện ~20%.

📊

Median-of-Three

Chọn pivot là trung vị của 3 phần tử (đầu, giữa, cuối) thay vì phần tử đầu. Partition cân bằng hơn → giảm ~14% comparisons.

🎯

3-Way Partitioning (Dijkstra)

Chia thành 3 phần: < pivot, = pivot, > pivot. Cực nhanh khi có nhiều phần tử trùng — complexity N log N → tuyến tính cho nhiều duplicates!

🔄

Dual-Pivot (Java default)

Chọn 2 pivot, chia mảng thành 3 phần. Java 7+ dùng cho Arrays.sort() với primitive types. Nhanh hơn ~10% nhờ cache.

🏗️

Tail Recursion Elimination

Đệ quy phần nhỏ hơn, lặp phần lớn hơn → stack depth luôn O(log N), tránh stack overflow cho mảng cực lớn.

💻 Code Java — 3-Way Quick Sort (Dijkstra)

Java 
private static void sort(Comparable[] a, int lo, int hi) {
    if (hi <= lo) return;
    int lt = lo, gt = hi;
    Comparable v = a[lo];              // pivot
    int i = lo + 1;
    while (i <= gt) {
        int cmp = a[i].compareTo(v);
        if      (cmp < 0) exch(a, lt++, i++); // a[i] < v → đưa sang trái
        else if (cmp > 0) exch(a, i, gt--);   // a[i] > v → đưa sang phải
        else              i++;               // a[i] == v → giữ nguyên
    }
    // a[lo..lt-1] < v = a[lt..gt] < a[gt+1..hi]
    sort(a, lo, lt - 1);
    sort(a, gt + 1, hi);
}
