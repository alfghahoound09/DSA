🔴 Selection Sort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Mỗi vòng lặp, tìm phần tử nhỏ nhất trong phần chưa sắp, rồi đổi chỗ nó với phần tử đầu tiên của phần chưa sắp.
🎴 Ví von thực tế

Giống như bạn có 1 đống bài lộn xộn. Bạn nhìn qua toàn bộ để tìm quân nhỏ nhất, rút nó ra đặt vào đầu. Rồi lại nhìn qua phần còn lại, tìm quân nhỏ nhất tiếp theo, đặt vào vị trí thứ 2... Cứ thế cho đến hết.

💻 Code Java — Selection Sort

Java 
public class Selection {
    public static void sort(Comparable[] a) {
        int N = a.length;
        for (int i = 0; i < N; i++) {           // duyệt từng vị trí
            int min = i;                           // giả sử a[i] nhỏ nhất
            for (int j = i+1; j < N; j++)        // tìm min thực sự
                if (less(a[j], a[min])) min = j;
            exch(a, i, min);                       // đổi chỗ a[i] ↔ a[min]
        }
    }

    private static boolean less(Comparable v, Comparable w) {
        return v.compareTo(w) < 0;
    }

    private static void exch(Comparable[] a, int i, int j) {
        Comparable temp = a[i]; a[i] = a[j]; a[j] = temp;
    }
}

⏱️ Compares

~N²/2 phép so sánh. Luôn quét hết phần còn lại.

🔄 Swaps

Chỉ N lần swap — ít nhất trong các sort cơ bản!

⚠️ Không Adaptive

Input đã sắp hay chưa đều chạy ~N²/2 comparisons.

🟢 Insertion Sort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Giống cách bạn sắp bài trên tay: lấy từng lá bài mới, rồi đẩy nó sang trái cho đến khi nó nằm đúng vị trí trong phần đã sắp.
🃏 Ví von thực tế

Khi chơi bài, tay trái bạn cầm các lá đã sắp. Tay phải rút 1 lá mới, rồi chen vào đúng vị trí giữa các lá bên tay trái. Nếu lá mới nhỏ hơn lá bên trái nó → đổi chỗ, cứ lùi dần cho đến khi đúng chỗ hoặc hết bên trái → dừng.

⚡ Điểm mấu chốt — DỪNG SỚM

Khi gặp phần tử bên trái ≤ mình → dừng ngay (else break). Đây là lý do Insertion Sort rất nhanh trên dữ liệu gần sắp (nearly sorted)!

💻 Code Java — Insertion Sort

Java 
public class Insertion {
    public static void sort(Comparable[] a) {
        int N = a.length;
        for (int i = 0; i < N; i++)                   // duyệt từng phần tử
            for (int j = i; j > 0; j--)                 // đi ngược về trái
                if (less(a[j], a[j-1]))             // nếu a[j] < a[j-1]
                    exch(a, j, j-1);                // đổi chỗ, tiếp tục lùi
                else break;                            // ĐÃ ĐÚNG CHỖ → dừng sớm!
    }
}

🏆 Best case: ~N

Input đã sắp → mỗi phần tử chỉ cần 1 compare → O(N)

💀 Worst case: ~N²/2

Input sắp ngược → mỗi phần tử phải swap đến đầu mảng

✅ Stable

Giữ nguyên thứ tự tương đối của các phần tử bằng nhau — quan trọng trong thực tế!

🔵 Shellsort — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Insertion Sort nhưng so sánh phần tử cách nhau h vị trí (thay vì 1). Giảm dần h cho đến 1 → mảng sắp xong.
🏃 Tại sao nhanh hơn?

Insertion Sort yếu vì: phần tử nhỏ ở cuối mảng phải nhích từng ô 1 để về đầu → rất chậm. Shellsort cho phần tử nhảy vọt h ô cùng lúc. Khi h giảm dần, mảng đã "gần sắp" → lúc h=1 (Insertion Sort thường), chỉ cần vài swap nữa!

💻 Code Java — Shellsort

Java 
public class Shell {
    public static void sort(Comparable[] a) {
        int N = a.length;

        int h = 1;
        while (h < N/3) h = 3*h + 1;    // Knuth: 1, 4, 13, 40, 121, ...

        while (h >= 1) {                    // giảm dần h
            for (int i = h; i < N; i++) {   // h-sort = Insertion Sort bước h
                for (int j = i; j >= h && less(a[j], a[j-h]); j -= h)
                    exch(a, j, j-h);
            }
            h = h / 3;                    // ..., 40 → 13 → 4 → 1
        }
    }
}

📊 Complexity

~O(N^{3/2}) với Knuth sequence — tốt hơn N² rất nhiều!

🌍 Thực tế

Dùng trong Linux kernel, bzip2, uClibc — code rất ngắn mà hiệu quả.

❓ Bài toán mở

Dãy h tối ưu vẫn chưa ai tìm được — vẫn là open problem!

🟡 Knuth Shuffle — Ý tưởng cốt lõi

💡 Ý TƯỞNG 1 CÂU
Duyệt từ trái sang phải, tại vị trí i chọn vị trí ngẫu nhiên r trong [0, i], rồi đổi chỗ a[i] và a[r]. Mọi hoán vị đều có xác suất bằng nhau.
⚠️ Lỗi cực kỳ phổ biến

Nếu chọn r trong toàn bộ [0, N-1] thay vì [0, i] → kết quả KHÔNG đều! Slide nhắc đến vụ kiện online poker vì dùng shuffle sai, gây thiệt hại hàng triệu đô.

💻 Code Java — Knuth Shuffle

Java 
public static void shuffle(Object[] a) {
    int N = a.length;
    for (int i = 0; i < N; i++) {
        int r = StdRandom.uniformInt(i + 1);  // random [0, i] ← quan trọng!
        exch(a, i, r);
    }
}

⏱️ O(N)

Chỉ duyệt 1 lần, mỗi phần tử swap 1 lần → tuyến tính.

🎯 Uniform

Mọi N! hoán vị đều có xác suất 1/N! — chứng minh được bằng quy nạp.
